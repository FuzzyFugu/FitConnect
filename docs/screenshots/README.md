# Screenshot exports

Place exported images of the live Agile tools here so they are versioned with
the report evidence:

- `product_backlog.png` — Trello backlog list
- `sprint_board_sprintN.png` — board state at each sprint
- `burndown_sprintN.png` — burndown chart per sprint
- `git_history.png` — `git log --graph` screenshot
- `retro_sprintN.png` — retrospective board

(These are captured from Trello/GitHub during the project, not backfilled.)
